# 四川省院前急救病情记录表 - Vue3 应用

这是一个基于Vue3开发的医疗急救病情记录表单应用，完全复现了四川省乐山市人民医院的院前急救病情记录表格式。

## 功能特性

- 📋 完整的医疗表单结构，包含四个主要部分：
  - 第一部分：基础信息及初次评估
  - 第二部分：院前急救医疗记录
  - 第三部分：转归情况
  - 第四部分：交接情况

- 🎯 主要功能模块：
  - 患者基本信息录入
  - 生命体征监测记录
  - 急救措施选择
  - 专科支持记录
  - 现场检查记录
  - 用药情况记录
  - 转归情况跟踪
  - 医护人员签名区域

- 💻 技术特点：
  - 使用Vue3 Composition API
  - 响应式数据绑定
  - 表单验证
  - 现代化UI设计
  - 移动端适配

## 安装和运行

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

应用将在 http://localhost:3000 启动

### 构建生产版本
```bash
npm run build
```

## 表单字段说明

### 基本信息
- 患者姓名、性别、年龄、身份证号
- 出警地址、联系电话
- 时间记录：接警、出发、到达现场、离开、到达医院

### 生命体征监测
- 血压(BP)、呼吸(R)、脉搏(P)、体温(T)
- 血氧饱和度(SPO2)、血糖
- 瞳孔反应、意识状态、呼吸状况

### 急救处理
- 急救措施记录（血压检测、心电监测、吸氧等）
- 专科支持（急诊科、骨科等）
- 现场检查、用药情况、院内准备

### 转归记录
- 患者去向、急救效果
- 交接时生命体征
- 其他备注信息

## 使用说明

1. 打开应用后，可以看到完整的医疗表单界面
2. 所有字段都支持实时编辑和数据绑定
3. 表单已预填充示例数据，可以直接查看效果
4. 支持打印功能，适合实际医疗场景使用
